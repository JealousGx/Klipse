# LTX-2 (Lightricks/LTX-2) — confirmed real system requirements from the official repo:
# Python >=3.12, CUDA >12.7, PyTorch ~=2.7. The repo's own setup uses `uv sync` against
# its packages/ workspace (ltx-core, ltx-pipelines) rather than plain PyPI packages —
# the git+subdirectory pip install below is a best-effort translation of that, not
# confirmed working; verify against https://github.com/Lightricks/LTX-2's own setup
# instructions once you have hands-on access, and prefer `uv sync` if pip install fails.
#
# torch + torchaudio are installed separately in the Dockerfile from PyTorch's own cu128
# index, not here from plain PyPI. ltx-core (this repo) depends on `torch~=2.7` (pinned)
# and bare, unpinned `torchaudio`, neither routed to a CUDA-specific index in ltx-core's
# own pyproject.toml — so installing them via this file's plain-PyPI resolution picks
# whatever's newest nvidia-cuda-*/torchaudio build at install time, which drifted to CUDA
# 13 packages against this image's CUDA 12.8 base and broke `libcudart.so` loading at
# model-load time. PyTorch's versioned cu128 index bundles a fixed, matching set for both.
