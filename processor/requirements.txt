# (LTX-Desktop's backend/pyproject.toml: `sageattention>=1.0.0; sys_platform != 'darwin'`),
# default-enabled in their production server (backend/ltx2_server.py) as a

# LTX-2 (Lightricks/LTX-2) — pinned to the exact commit Lightricks' own shipped product
# (LTX-Desktop) uses (backend/pyproject.toml's [tool.uv.sources] rev), not `main`. `main`
# has since diverged in ways that broke every API assumption sourced from LTX-Desktop's
# code during earlier development (confirmed: DistilledPipeline gained a
# compilation_config/CompilationConfig param on `main` that doesn't exist at all on this
# commit, which only has a plain `torch_compile: bool` — see inference/model.py). Pinning
# to this commit means our code's actual runtime API matches the API we're reading and
# reasoning about.
#
# torch + torchaudio + torchvision are installed separately in the Dockerfile from
# PyTorch's own cu128 index (see Dockerfile for the exact versions, matching this same
# commit's uv.lock), not here from plain PyPI — ltx-core's own pyproject.toml doesn't
# route them to a CUDA-specific index, so resolving them via this file's plain-PyPI
# resolution drifts to a mismatched CUDA build or is missing entirely (torchvision).
